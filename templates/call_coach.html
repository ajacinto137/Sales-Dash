Set up (once)

  1. In HubSpot, set calling to call from browser (not your phone).
  2. Download the extension above and unzip it.
  3. Open chrome://extensions, turn on Developer mode, click Load unpacked and pick the call-coach-extension folder.
  4. Pin it, and stay signed in to Sales-Dash in the same Chrome profile.

On every call

  1. On the HubSpot tab, click the Call Coach icon → the side panel opens.
  2. Press Start coaching (the first time, allow the microphone).
  3. Tell the customer: “{{ playbook.get('consent_line') }}”
  4. Read the big card when it appears. Press Stop when the call ends.
